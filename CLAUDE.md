# Règles pour Claude Code sur ce projet

- Ne jamais lancer de commande git (pas de add, commit, push, checkout, etc.). Stéphanie gère git elle même.
- Avant d'écrire ou de modifier un fichier, toujours montrer le contenu prévu et attendre une validation explicite de Stéphanie avant d'écrire réellement.
- Ne jamais lancer de commande terminal à la place de Stéphanie (npm install, npm run, etc.) : lui indiquer la commande à taper, elle l'exécute elle même.
- Ne jamais créer de dossier, renommer ou supprimer un fichier de sa propre initiative. En cas de doute, toujours demander avant d'agir.
- Projet d'apprentissage : Stéphanie est développeuse frontend/iOS, peu familière avec le backend. Prioriser des explications claires à chaque étape plutôt que la rapidité d'exécution.
